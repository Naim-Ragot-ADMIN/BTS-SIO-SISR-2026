Windows Server et Active Directory

Des bases serieuses pour automatiser un lab AD, creer des utilisateurs en masse, configurer DHCP et monter un site IIS.

Deployer une foret Active Directory

Installe le role AD DS, verifie les prerequis et cree une nouvelle foret avec DNS integre.

PowerShell
AD DS Windows Server Labo / maquette

Prerequis: console admin, Windows Server, mot de passe DSRM securestring.

Telecharger Source officielle 
param(
    [Parameter(Mandatory = $true)]
    [string]$DomainName,

    [Parameter(Mandatory = $true)]
    [securestring]$SafeModeAdministratorPassword,

    [string]$DomainNetbiosName = "",
    [string]$DatabasePath = "C:\\Windows\\NTDS",
    [string]$LogPath = "C:\\Windows\\NTDS",
    [string]$SysvolPath = "C:\\Windows\\SYSVOL",
    [switch]$NoRebootOnCompletion
)

Set-StrictMode -Version Latest
$ErrorActionPreference = "Stop"

Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools
Import-Module ADDSDeployment

$commonParams = @{
    DomainName                    = $DomainName
    DomainNetbiosName             = $DomainNetbiosName
    SafeModeAdministratorPassword = $SafeModeAdministratorPassword
    InstallDns                    = $true
    CreateDnsDelegation           = $false
    DatabasePath                  = $DatabasePath
    LogPath                       = $LogPath
    SysvolPath                    = $SysvolPath
}

Test-ADDSForestInstallation @commonParams
Install-ADDSForest @commonParams -Force:$true -Confirm:$false

Importer des utilisateurs et OU depuis un CSV

Cree automatiquement les OU, les comptes et les groupes de base a partir d'un fichier CSV.

PowerShell
Active Directory CSV Onboarding

Colonnes attendues: GivenName,Surname,SamAccountName,UserPrincipalName,OU,DisplayName,Department,Title,Group.

Telecharger Source officielle 
param(
    [Parameter(Mandatory = $true)]
    [string]$CsvPath,
    [Parameter(Mandatory = $true)]
    [string]$RootDN,
    [Parameter(Mandatory = $true)]
    [securestring]$DefaultPassword
)

Import-Module ActiveDirectory
$users = Import-Csv -LiteralPath $CsvPath

foreach ($user in $users) {
    $ouName = if ($user.OU) { $user.OU.Trim() } else { "Utilisateurs" }
    $ouDn = "OU=$ouName,$RootDN"
    $displayName = if ($user.DisplayName) { $user.DisplayName } else { "$($user.GivenName) $($user.Surname)" }

    if (-not (Get-ADOrganizationalUnit -LDAPFilter "(distinguishedName=$ouDn)" -ErrorAction SilentlyContinue)) {
        New-ADOrganizationalUnit -Name $ouName -Path $RootDN -ProtectedFromAccidentalDeletion $true | Out-Null
    }

    if (-not (Get-ADUser -Filter "SamAccountName -eq '$($user.SamAccountName)'" -ErrorAction SilentlyContinue)) {
        New-ADUser -Name $displayName -GivenName $user.GivenName -Surname $user.Surname `
            -DisplayName $displayName -SamAccountName $user.SamAccountName `
            -UserPrincipalName $user.UserPrincipalName -Department $user.Department `
            -Title $user.Title -Path $ouDn -AccountPassword $DefaultPassword `
            -ChangePasswordAtLogon $true -Enabled $true
    }
}

Deployer DHCP et preparer une zone DNS

Installe le role DHCP, autorise le serveur dans l'AD, cree une plage IPv4 et pose les options principales.

PowerShell
DHCP DNS Reseau local

Adapte aux labs SISR pour automatiser les scopes et les options DNS / passerelle.

param(
    [Parameter(Mandatory = $true)]
    [string]$ScopeName,
    [Parameter(Mandatory = $true)]
    [ipaddress]$StartRange,
    [Parameter(Mandatory = $true)]
    [ipaddress]$EndRange,
    [Parameter(Mandatory = $true)]
    [ipaddress]$SubnetMask,
    [Parameter(Mandatory = $true)]
    [ipaddress]$ScopeId,
    [Parameter(Mandatory = $true)]
    [ipaddress]$Router,
    [Parameter(Mandatory = $true)]
    [ipaddress[]]$DnsServers,
    [Parameter(Mandatory = $true)]
    [string]$DnsDomain
)

Install-WindowsFeature -Name DHCP -IncludeManagementTools
Import-Module DhcpServer

netsh dhcp add securitygroups | Out-Null
Restart-Service -Name DHCPServer -Force

Add-DhcpServerv4Scope -Name $ScopeName -StartRange $StartRange.IPAddressToString `
    -EndRange $EndRange.IPAddressToString -SubnetMask $SubnetMask.IPAddressToString -State Active

Set-DhcpServerv4OptionValue -ScopeId $ScopeId.IPAddressToString `
    -DnsDomain $DnsDomain `
    -DnsServer ($DnsServers | ForEach-Object { $_.IPAddressToString }) `
    -Router $Router.IPAddressToString

Deployer un site IIS et son App Pool

Installe IIS, cree un pool d'applications, deploie le site et le demarre automatiquement.

PowerShell
IIS WebAdministration Publication

Pratique pour une maquette intranet, un portail local ou un serveur web Windows en labo.

Telecharger Source officielle 
param(
    [Parameter(Mandatory = $true)]
    [string]$SiteName,
    [Parameter(Mandatory = $true)]
    [string]$PhysicalPath,
    [int]$Port = 80,
    [string]$HostHeader = "",
    [string]$AppPoolName = ""
)

Install-WindowsFeature -Name Web-Server -IncludeManagementTools
Import-Module WebAdministration

if (-not $AppPoolName) { $AppPoolName = $SiteName }
if (-not (Test-Path -LiteralPath $PhysicalPath)) { New-Item -ItemType Directory -Path $PhysicalPath -Force | Out-Null }
if (-not (Test-Path -LiteralPath "IIS:\\AppPools\\$AppPoolName")) { New-WebAppPool -Name $AppPoolName | Out-Null }
if (-not (Test-Path -LiteralPath "IIS:\\Sites\\$SiteName")) {
    New-Website -Name $SiteName -Port $Port -HostHeader $HostHeader `
        -PhysicalPath $PhysicalPath -ApplicationPool $AppPoolName | Out-Null
}
Start-Website -Name $SiteName

Une base simple pour lancer rapidement Zabbix et Grafana sur un hote Linux avec Docker.

Deployer Zabbix + Grafana via Docker

Clone le depot officiel Zabbix Docker, lance la stack de base puis demarre un conteneur Grafana avec volume persistant.

Bash
Zabbix Grafana Docker

Prerequis: Docker et Docker Compose deja installes, acces internet et machine Linux ou VM labo.

Telecharger Source Zabbix Source Grafana 
#!/usr/bin/env bash
set -euo pipefail

ZABBIX_VERSION="${ZABBIX_VERSION:-7.4}"
WORKDIR="${WORKDIR:-/opt/monitoring}"
ZABBIX_REPO="${WORKDIR}/zabbix-docker"
GRAFANA_VOLUME="${GRAFANA_VOLUME:-grafana-storage}"

mkdir -p "${WORKDIR}"

if [ ! -d "${ZABBIX_REPO}/.git" ]; then
  git clone https://github.com/zabbix/zabbix-docker.git "${ZABBIX_REPO}"
fi

cd "${ZABBIX_REPO}"
git fetch --tags --force
git checkout "${ZABBIX_VERSION}"

docker compose -f docker-compose_v3_alpine_mysql_latest.yaml up -d
docker volume create "${GRAFANA_VOLUME}" >/dev/null

if ! docker ps -a --format '{{.Names}}' | grep -qx 'grafana'; then
  docker run -d --name grafana --restart unless-stopped -p 3000:3000 \
    -v "${GRAFANA_VOLUME}:/var/lib/grafana" grafana/grafana-enterprise
fi
